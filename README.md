# xdecaro Photos

`com_xdecarophotos` is the centralized photo service for the xdecaro Joomla ecosystem.

Target: Joomla 6.1.3+; Core by xdecaro 2.1.0+.

## Prima milestone 0.1.0

- Joomla 6.1.3+ only
- Core by xdecaro 2.1.0+
- riferimenti cross-component via `EntityReference`
- upload JPEG/PNG/WebP validato dal contenuto
- originale preservato, varianti separate
- preset Avatar e Fototessera
- Gallery amministrativa responsive
- Photo Studio con upload sempre disponibile e camera come progressive enhancement

Build: `bash build/build.sh`.
